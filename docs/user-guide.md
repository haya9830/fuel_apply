# 月末の記録方法

## はじめに

管理者から受け取ったURLをスマートフォンで開きます。アプリストアや開発環境は必要ありません。iPhoneではSafariの共有メニューから、AndroidではChromeのメニューからホーム画面に追加できます。

初回起動とExcelへの保存時にはインターネット接続が必要です。アプリ本体を一度読み込んだ後は、圏外でも入力できます。

## 入力と保存

1. 対象月を確認します（例：`2026-11`）。
2. 記録する機械の「月末アワーメーター」に、機械に表示された累積時間をそのまま入力します。入力した機械は自動で選択されます。
3. 「入力内容を確認する」を押し、機械名と値を確認します。
4. 「Excelへ保存」を押します。Googleへの接続画面で、管理者から案内されたアカウントを使います。
5. 対象月のExcelを選びます。「○台の月末アワーメーターをExcelに保存しました」と表示されたら完了です。

下書きはその端末の中に保存されます。ほかの端末には移りません。ブラウザのデータ削除やプライベートブラウズでは下書きが失われることがあるため、保存完了を確認してください。

## 修正する場合

保存済みの値を変更するときだけ、確認画面の「入力済みの記録を上書き」を選択します。前月末の値を下回る場合は保存が止まります。機械のメーター交換などがあった場合は管理者へ確認してください。

## 保存できなかった場合

入力は消さずに残ります。接続を確認して、同じ内容でもう一度保存できます。Googleの接続画面が開かない場合は、ポップアップを許可して再試行します。

保存中は、ほかの端末やExcelアプリで同じファイルを編集しないでください。日別の稼働時間・給油量などは、このアプリとは別に帳票へ記入します。
